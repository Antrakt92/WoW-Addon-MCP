# Security policy

Please report vulnerabilities privately through GitHub's **Security → Report a vulnerability** flow for this repository. Do not open a public issue for an undisclosed vulnerability.

The installed server communicates over stdio and serves the bundled, versioned Retail and Forever catalogs. Operator configuration can also supply local JSON observation files and a Battle.net installation directory for build metadata. MCP tool arguments select records within those configured sources. Dataset generation and npm publishing use separate maintainer commands and workflows. The optional in-game collector runs as a WoW addon.
